## 2. Global Cannibalization Guard & URL Routing Rules

To prevent search engine confusion, ranking cannibalization, and duplicate content penalties:
1. **Single Primary Intent per URL:** Exactly one primary keyword is assigned to each URL. No two URLs in the catalog compete for the identical primary keyword.
2. **Category Hubs vs Tool Pages:** Category pages (e.g. `categories/coding.html`) rank for plural exploratory searches (`best ai coding tools`, `coding assistants in pakistan`). Individual tool pages (e.g. `tools/cursor-pro.html`) rank strictly for singular transactional/pricing searches (`buy cursor pro`, `cursor pro price in pakistan`).
3. **Comparison Pages vs Tool Pages:** Head-to-head comparison queries (`chatgpt vs claude`) resolve exclusively to `compare/chatgpt-vs-claude.html`. Tool pages interlink contextually to the comparison page without competing for comparison search terms.
4. **Editorial Best Listicles vs Hubs:** `/best/best-ai-coding-tools.html` is an editorial benchmark review with comparative testing tables, while `/categories/coding.html` is a faceted commercial catalog hub.
